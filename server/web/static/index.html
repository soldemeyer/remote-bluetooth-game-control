RBGC Server

Server

The server starts switched off. Turning it on opens the client port; turning it off closes it and stops discovery. Paired Bluetooth controllers stay connected either way, so a console does not drop when you toggle this.

Accept client connections
Off means no client can connect or stream.
Identity

Leave a password blank to keep it. Changing the client password disconnects connected clients — the session key is derived from it, so they must re-authenticate. Setting an admin password separates GUI access from the password players use.

Visibility

With Internet enabled and visibility set to Broadcast, this server's name is listed on the broker so clients can pick it. Hidden servers are never listed — the broker only ever relays; it never sees your password or your input.

Bluetooth adapters

Capacity equals the number of enabled adapters. Enable up to four. Put an adapter into connection mode, then start pairing on the console.

Clients

Approve a client to let its controllers reach a console, then assign each controller to an adapter.
