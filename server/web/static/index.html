Split-screen view —

Drag a region onto a controller — or click the region and then the controller, which is the way in on a touchscreen — to show that player only that part of the screen. Each controller can hold one region from each layout, so it works whichever way the game splits — the one matching the layout on screen is highlighted. A controller with nothing assigned sees the whole picture.
