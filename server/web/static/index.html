RBGC Server

Server

The server starts switched off. Turning it on opens the client port; turning it off closes it and stops discovery. Paired Bluetooth controllers stay connected either way, so a console does not drop when you toggle this.

Client connections
On this network (LAN, VPN, port forward)
Clients that reach this server's address directly.
Over the Internet (hole-punch)
Clients introduced by the rendezvous broker.

These apply the moment you change them. Both off means nobody can connect. Paired Bluetooth controllers stay connected either way, so toggling these never disturbs a console mid-game.

Identity

Leave a password blank to keep it. Changing the client password disconnects connected clients — the session key is derived from it, so they must re-authenticate. The admin password guards this page; without a separate one, any player who can connect a controller can also approve clients and re-pair adapters.

Visibility

Hidden does not mean unreachable: a client that already knows the address (or room code) still connects. The broker only ever relays — it never sees your password or your input.

Bluetooth adapters

Capacity equals the number of enabled adapters. Enable up to four. Put an adapter into connection mode, then start pairing on the console.

Clients

Approve a client to let its controllers reach a console, then assign each controller to an adapter.

Video

Stream the console's picture to your players. Video travels straight from the capture machine to each client — it does not pass through this server.
